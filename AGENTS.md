# Project instructions

Keep `README.md`, `INSTALL.md` and `AI-INSTALL-PROMPT.md` in sync whenever changing
installation routes, supported platforms, dependencies, initial configuration,
startup, updates, recovery or uninstall behavior. Update every affected document
in the same change. Check the actual installer and launcher rather than relying
on older documentation.

Review `docker/README.md` and the instructions generated by the package builders
when their routes are affected. Before releasing a package, verify its bundled
instructions reflect the same workflow. Source documentation edits do not update
already published packages; report that distinction accurately.
